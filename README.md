# QKI K 线终端

QKI 主网（Chain ID 20181205）只读链上行情工具。

在线访问：https://bu-qi.github.io/qki-cct-candles/

## 功能

- 常用代币快捷入口：CCT2、GAS、WQKI；也可输入其他代币合约。
- CCT2、WQKI 默认 USDT 计价；GAS 默认 QKI 计价；可切换已核实存在的直接交易池。
- CCT2 对应当前的 Chain Chat Token；QKI 计价对应 WQKI 池。常用池地址与代币精度已核对，点击后直接读取成交，省去重复查找池。
- 1 分钟、5 分钟、15 分钟、1 小时、4 小时、北京时间日线。
- K 线、折线、MA5/10/20、成交量、鼠标缩放和平移。
- 最近成交可跳转区块浏览器核验，支持加载更早成交、导出 CSV。
- 每 30 秒尝试更新，使用本地缓存加快再次打开。

## 运行

无需构建和安装依赖。用任意静态 HTTP 服务器提供 `dist/` 目录，例如：

```sh
python -m http.server 8080 --directory dist
```

打开 http://localhost:8080 。请通过 HTTP 服务器访问，以便加载 JavaScript 模块。

计算检查（Node.js 22 或更新版本）：

```sh
node tests/market.mjs
```

## 数据口径

数据来自 QKI Blockscout 的指定 Qkswap V2 池 Swap 事件。价格为池内交换的计价币数量除以代币数量，成交量按基础代币计算。仅展示当前已加载范围，不表示全市场或完整 24 小时行情。最早 K 线可能不完整；无成交时段沿用上一收盘价、成交量为零。

多跳路由、转账税、Gas 和滑点可能使钱包实际成本与池内成交价不同。均线只使用已加载 K 线；过长的分钟级历史范围会提示切换更长周期。数据接口可能延迟或限流。

`seed.json` 是创建页面时读取的真实历史成交快照，首次打开后会尝试获取最新索引数据；接口失败时页面会标明缓存/更新失败状态。它不是实时行情文件。
